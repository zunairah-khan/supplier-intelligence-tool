# Supply Chain Risk Management Web Application

A React web application that helps organisations with complex supply chains understand and manage supplier risk, built for my BSc (Hons) Digital & Technology Solutions dissertation at BPP University.

## Tech Stack

- React
- Tailwind CSS
- D3.js (supplier tier map visualisation)
- Vitest (unit testing)

## Run Locally

Run `npm install`, then `npm run dev`. Run tests with `npm test`.
